# Provider marks

Marks identify the provider; they belong to their owners.

Codex and Antigravity paths: [LobeHub](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg@1.95.1` (MIT). Source files:
[codex.svg](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/codex.svg)
and [antigravity.svg](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/antigravity.svg).
Their pinned Git blob SHAs are recorded in ProviderLogo.tsx. The package metadata
at retrieval reports version 1.95.1. Codex uses currentColor; Antigravity's mono
path uses a single four-stop Google-color gradient.

Claude and Google Gemini paths: `simple-icons@16.34.0` (CC0-1.0),
[claude.svg](https://github.com/simple-icons/simple-icons/blob/16.34.0/icons/claude.svg)
and [googlegemini.svg](https://github.com/simple-icons/simple-icons/blob/16.34.0/icons/googlegemini.svg).
[CC0 dedication](https://github.com/simple-icons/simple-icons/blob/16.34.0/LICENSE.md).
Claude uses coral #D97757; Gemini uses blue #3186FF and is display-only.

Paths were optimized once with SVGO 4, convertPathData and cleanupNumericValues,
float precision 2, using SVGOMG's worker (Git blob
5837971b4a117e7a93a587650267c0dc38fb74c4). These paths are embedded inline;
no icon package or optimizer is shipped as a dependency. No filters or masks.

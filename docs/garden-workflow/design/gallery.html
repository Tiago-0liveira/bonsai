A terminal overlay uses solid colored cells and box borders. At 80 × 24 it expands to a focused sheet. Color always accompanies a written state or symbol.

Designed to fit a terminal

  • Every glyph, filled surface, rail, border and action occupies whole cells on the reference 11 × 26 grid. No gradients, blur, transparency, freeform illustrations or rounded pixel controls appear inside the TUI.
  • The application shell, olive palette, DejaVu Sans Mono, shaded submenu and focus footer follow revision 02. Muted blue, cyan and plum add phase distinctions; amber marks decisions and red marks blockers.
  • Wide ticket overlays keep the parent visible with dimmed solid colors. Compact layouts use a nearly full-screen sheet. Focus belongs to the sheet; Escape returns to the original selection. Long content scrolls within the active section.
  • Mouse targets map to cell rectangles. Keyboard activation is equivalent: arrows select, Enter opens, Tab moves between overlay actions. Opening an item never runs a mutation.
  • Private draft recovery, grouped phases and the one-pass reviewer are proposed product behavior. Existing verified approvals, account isolation and GitHub freshness boundaries remain requirements.

Feasibility reference: Charm's cell-based styling and composition. The current Bonsai dependency is Lip Gloss v1; these sketches require no dependency change and make no claim that its v2 compositor is already installed.
